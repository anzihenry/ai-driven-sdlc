# Delivery Checklist

Use this checklist before merging AI-assisted work.

## Spec

- [ ] Requirement is written down
- [ ] Scope is explicit
- [ ] Acceptance criteria are testable

## Implementation

- [ ] Changed files match the requested scope
- [ ] Risky assumptions are documented
- [ ] Error handling is present

## Quality

- [ ] Tests were added or updated when applicable
- [ ] Manual verification was completed
- [ ] Logs or observability needs were considered

## Review

- [ ] Human reviewed the final change
- [ ] AI-generated code was challenged, not just accepted
- [ ] Follow-up work was captured if anything was deferred
