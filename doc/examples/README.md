# Example Adoption Paths

This directory contains lightweight example adoption paths for the AI-Driven SDLC Template.

Examples should prove that the template can be followed in realistic situations without turning this repository into a monorepo of sample applications.

## Example Rules

- Prefer documented walkthroughs before adding runnable sample projects
- Keep each example tied to a specific repository type from `doc/process/multi-stack-adoption.md`
- Explain the adoption level, repository type, retained surfaces, customized surfaces, and validation checks
- Record gaps or hidden assumptions in a paired validation notes file
- Avoid adding stack-specific dependencies unless they validate an important template claim

## Current Example Model

The first Phase 3 example uses a documentation or template repository adoption path.

This model validates the template's own workflow while keeping examples lightweight and stack-agnostic.
